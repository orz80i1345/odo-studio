# odo-studio

`odo-studio` 是河日 Ode Studio 的前台預約網站專案。

## 專案定位

- 用途：展示空間、佈景、價格、FAQ，並提供使用者線上預約與查看自己的預約狀態。
- 主要 app：`apps/booking-web`
- 共用套件：`packages/shared`
- 專案說明：`docs/`
